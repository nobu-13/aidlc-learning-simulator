## 3. Deployment Architecture — CloudFront + OAC + Private S3

バックエンド・コンピュートを持たない静的 SPA（React 18 + TypeScript + Vite）。
採点・伝播などのロジックはすべてブラウザ内の決定的エンジンで動作し、永続化は
localStorage の学習進捗のみ（外部送信なし）。AWS は配信面のみを担う。

```
Browser ──HTTPS──▶ CloudFront (E1MPX5NEN76JKH) ──OAC / SigV4──▶ Private S3 origin
                    d1s9ig7adbe2qs.cloudfront.net                (Block Public Access ON)
```

- **CloudFront が唯一の公開面**: `ViewerProtocolPolicy = redirect-to-https`、許可メソッドは `GET/HEAD` のみ、
  `PriceClass_100`、デフォルトルート `index.html`。
- **OAC (Origin Access Control)**: CloudFront は S3 の REST エンドポイントを **SigV4 署名**して読む。
  S3 website エンドポイントは使わない。
- **Private S3 origin**: Block Public Access 4 フラグすべて `true`、SSE-S3 (AES256) 暗号化、
  バージョニング有効（成果物ロールバック用）。バケットポリシーはこの CloudFront distribution
  （`aws:SourceArn` スコープ）からの読み取りのみ許可し、非 TLS リクエストは拒否。
- **SPA fallback**: OAC + private S3 は欠損キーに 403 を返すため、CloudFront が 403/404 を
  ともに `/index.html`（HTTP 200）へマッピングし、ディープリンク・リロードを成立させる。
